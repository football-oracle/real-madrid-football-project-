This project is a complete Football Team Management System built using Python (Tkinter & ttkbootstrap) and Oracle SQL Database.



Features:

Full CRUD (Create, Read, Update, Delete) operations for Players, Coaches, Medical Records, Achievements, and Stadiums.

Automatic ID generation (Increment/Decrement) using Oracle Triggers.

Custom Oracle Functions to format salaries and calculate total team salaries.

Clean, user-friendly graphical interface.



Files:

project.sql: Contains the Oracle database schema, triggers, and functions.

real_madrid_management.py: Contains the Python GUI application code.
